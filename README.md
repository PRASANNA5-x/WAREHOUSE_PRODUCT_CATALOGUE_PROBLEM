# Warehouse Product Catalogue

A lightweight warehouse catalogue management app built with plain HTML, CSS, and JavaScript.

## Features

- Add products with an ID, name, price, quantity, and warehouse.
- Edit product details and delete products from the catalogue.
- View products in a table.
- Sell a chosen quantity of a product, with checks for valid input and available stock.
- Prevent duplicate product IDs.

## Run the app

Open `index.html` in a modern web browser. No installation or build step is required.

Product data is kept in memory, so it resets when the page is refreshed or closed.
